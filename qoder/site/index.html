隔几天回来，忘记上次进展、失败尝试和下一步？
保存一次记录，下次打开就有有依据的进度回顾和续做清单。

解决什么问题

进展记不清

隔几天回到课题，想不起上次做到哪一步、哪些已经验证过。

失败被重复

曾经踩过的坑、试过的方法没有沉淀，反复重试同样的错误。

下一步不明确

缺少一份基于真实记录的续做清单，重新进入状态成本高。

核心功能

研究项目与目标

创建项目并录入研究目标，项目标识与 scope 由后端选择保存。

结构化保存

记录本次进展、已尝试方法、遇到的问题、下一步，真实写入 PowerContext，成功才提示。

重开召回

重新打开应用，按项目召回历史，展示可追溯原始记录与续做清单，每条带来源引用。

项目隔离

项目 A 的记录不会出现在项目 B；PowerContext 不可用时如实报错，不伪造历史。

技术架构

浏览器（轻量 Web UI） → 服务端代理（Python 标准库，持有凭据） → PowerContext 1.5.1（SQLite 持久化）

  • 不使用进程内数组或浏览器 localStorage 充当记忆。
  • 续做清单由「结构化输入 + 确定性模板」生成，无需模型密钥，绝不编造未发生的进展。
  • PowerContext token 只在服务端，绝不下发浏览器或写入日志；证据中统一脱敏。

体验方式（本地）

  1. 启动 PowerContext（SQLite 轻量模式）：scripts/start_powercontext.ps1
  2. （可选）copy .env.example .env，配置 POWERCONTEXT_URL 等
  3. 启动应用：scripts/start_app.ps1（或 python server.py）
  4. 打开 http://127.0.0.1:8688/
  5. 运行真实验收：python tests/verify_samples.py

需要本机可用的 powercontext 可执行（参考版本 1.5.1）。

边界

scope_id 是数据分区、不是授权。本演示版仅支持单人本地使用，不宣称多租户隔离；公网/多人使用需另加可信鉴权。
